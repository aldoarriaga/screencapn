# Contributing to Screen Cap'n

Thanks for helping improve Screen Cap'n.

Please follow these contribution rules:

- Create a focused, typed branch before any tracked change.
- Keep unrelated changes out of the branch.
- Add tests appropriate to the behavior and risk.
- Run the relevant formatting, checks, and tests before review.
- Do not commit credentials, local captures, build output, or certification
  artifacts.
- Keep user-facing behavior and documentation aligned.

Open an issue first when the expected behavior or scope needs product discussion.
